# Interactive Game Website

A 3D interactive website built with Three.js. Here you can play the game Kauwe Bende.

## Features

- Interactive 3D cards
- Hover animations
- Gyro effects on mobile

## Tech Stack

- Three.js
- Vite
- JavaScript
- WebGL

## Development

Install dependencies:

npm install

Run locally:

npm run dev

I included a .bat script to automatically run this line in a terminal.
